# The Local Tavern and Grille website
Static responsive website. Open `index.html` or serve the directory with any static web server.

## Pages
- `index.html` — homepage
- `menu.html` — full menu with sticky category navigation
- `visit.html` — address, phone, directions, verified experience details and hours verification notice

## Accuracy / launch verification
Complete weekly closing hours, official online-ordering URL, reservations, and official social accounts were not established by the supplied source and are therefore not fabricated.

## Photography
Files in `assets/authentic/` are user-supplied restaurant imagery. Higgsfield image URLs are supplementary editorial food imagery generated from verified menu descriptions and are labeled accordingly where context requires it.
